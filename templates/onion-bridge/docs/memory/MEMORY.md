# Project Memory

Project-owned durable decisions and context live here.

Record only information that will materially help future work, such as:
- confirmed product or technical decisions;
- stable API or behavior agreements;
- constraints that future tickets must respect;
- important rationale that is not obvious from source code.

Do not copy chat history, temporary progress, logs, or Acorn Harness rules here.
Keep entries short and point to authoritative project artifacts when they exist.
