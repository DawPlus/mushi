# T-261005-06 — KakaoTalk delivery + “today’s secret” chatbot skill

## Goal
Deliver the rotated Serve URL + control secret to the owner over **KakaoTalk**, and support a simple chatbot-style request (“오늘 비번/링크”) that runs the same rotate/handoff flow.

## Design (locked)
- **Channel:** KakaoTalk.
- **Outbound (daily / after rotate):** Kakao REST **나에게 보내기** (`/v2/api/talk/memo/default/send` or current docs equivalent) using the owner’s OAuth access token with `talk_message` scope. Text template includes Serve HTTPS URL + control secret.
- **Chatbot:** Kakao **오픈빌더** 스킬 서버(webhook) → Onion helper. Intents:
  - secret/link/rotate → `T-261005-05` handoff
  - server on → `LifecyclePort.up()` (web + Tailscale Serve)
  - server off → `LifecyclePort.stop()`
  - status → `LifecyclePort.status()`
- **Auth storage:** Kakao keys/tokens only in gitignored `~/.onion-bridge/kakao.json` (0600). Setup steps: `docs/KAKAO_SETUP.md` (owner collects keys while other tickets build).
- **LLM-ready:** skill router uses `IntentPort`. v1 = keyword/rules. Later swap to SpaceXAI (`XAI_API_KEY`, `https://api.x.ai/v1`) without rewriting Kakao or rotate cores. Notifier stays `HandoffNotifierPort` (Kakao adapter).

## Do
- Follow `docs/KAKAO_SETUP.md`; implement token refresh + 나에게 보내기 client.
- After rotate (`--notify=kakao` or chatbot), send URL + secret + day note.
- Skill-server webhook: rotate / up / stop / status mapped to ports above.
- Document 오픈빌더 wiring + daily `launchd` → `pnpm rotate --notify=kakao`.
- Document Kakao “나에게 보내기” weak notification behavior; skill chat reply as fallback.
- Keep IntentPort interface documented for future SpaceXAI adapter (no LLM required to ship).

## Keep
- Do not commit Kakao secrets or access tokens.
- Do not build a full multi-user Kakao channel product; owner-only.
- Do not replace Tailscale auth with Kakao login for the dashboard.
- Do not scrape unofficial Kakao APIs.
- Do not hard-require LLM to ship v1.

## Done
- Owner can complete Kakao setup once and receive URL+secret in Kakao after rotate.
- Chatbot skill path can request today’s handoff and get URL+secret back.
- Docs cover setup, token refresh, and failure modes (scope missing, Serve disabled, token expired).
