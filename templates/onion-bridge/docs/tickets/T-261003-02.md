# T-261003-02 — Web dashboard and settings UI

Superseded by `T-261003-01`. FE and BE are now handled together by one worker.

## Goal
Build the TanStack web UI for choosing a project folder, starting/stopping Onion, viewing active connection state, and editing basic settings.

## Do
- Add dashboard route showing current Onion status and active workspace.
- Add project picker UI backed by the control API.
- Add start/stop controls with loading, success, and error states.
- Add settings route for project/folder sources and backend connection settings required by the MVP.
- Wire UI to the backend API contract from `T-261003-01`.

## Keep
- Keep UI inside `apps/web`.
- Avoid secrets in browser state, logs, or rendered settings.
- Prefer simple native controls before extra UI dependencies.

## Done
- `apps/web` builds successfully.
- Dashboard can show idle, starting/running, stopping, and error states.
- User can pick a project and trigger start/stop through the backend API.
- Settings page can view/update MVP settings required by backend.
